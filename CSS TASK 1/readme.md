<h1> CSS Task 1 - E-Commerce Layout</h1>
A practical task focused on building a clean and structured layout for an e-commerce page.

Key Learnings & Applied Concepts:

Flexbox Layout: Structuring and aligning the header, navigation menus, and product collections flexibly.

CSS Reset & Base Rules: Normalizing browser defaults using margin, padding, and box-sizing: border-box.

CSS Calculations: Utilizing calc() to dynamically handle widths and item spacing.

Asset Management: Structuring and styling icons and images (SVG and WebP formats).
